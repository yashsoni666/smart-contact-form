# Smart Contact Form with Spam Detection (AIML)

## 📌 Project Overview
This project is an AI-powered web application that detects whether a user-submitted message is **Spam** or **Genuine (Ham)** using Machine Learning.  
It is built using **Python, Flask, Scikit-learn, and SQLite**.

## 🚀 Features
- Spam detection using Naive Bayes classifier
- Real-time message analysis
- Clean UI with HTML & CSS
- SQLite database to store messages and predictions
- Admin dashboard to view message history

## 🛠️ Tech Stack
- Python
- Flask
- Scikit-learn
- Pandas
- SQLite
- HTML, CSS

## 🧠 Machine Learning
- Algorithm: Multinomial Naive Bayes
- Text Vectorization: CountVectorizer
- Dataset: Custom spam/ham dataset
